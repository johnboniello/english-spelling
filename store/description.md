## App name (max 30 characters)

Spelling EN: Spelling Practice

## Short description (max 80 characters)

Practice weekly English spelling words, with list scanning and family sync.

## Full description

I built Spelling EN for my own daughter, to help her practice her weekly English spelling words at home. It is the English version of my French dictée app, which she liked so much that I made the same thing for English.

The app includes three practice modes. Scrambled Letters presents the letters of a word out of order, to be dragged back into place. Pick the Spelling reads a word aloud and offers four spellings to choose from; the wrong choices are the mistakes children really make in English, like "freind" or "recieve". Write the Word reads a word aloud to be written out on paper, then typed in and checked, with the wrong letters shown so they can be fixed.

A word list can be typed in directly, or scanned from a photo using the camera. That photo is processed entirely on the device, so it is never uploaded anywhere.

Progress is tracked automatically. Words that are missed come back for extra review until they are spelled right a few times, and correct answers are met with a small animation, so practice stays encouraging rather than repetitive.

An optional sync feature allows the same word list to be shared across devices, using a randomly generated code rather than an account or email address. This makes it possible for a child to practice on more than one device, or for a parent or grandparent to review the same list, without creating a login.

There are no ads, no required accounts, and no tracking. I built this to be a simple, focused tool for a real need in my own house, and I am glad to share it in case it helps yours as well.
