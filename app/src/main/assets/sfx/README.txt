Sound effects for right / wrong answers.

  correct.wav  — played on a correct answer (also: the voice says "Bravo !")
  wrong.wav    — played on a wrong answer (also: the voice says "Essaie encore")

Simple placeholder tones are bundled here. To use nicer sounds, replace these
files (keep the same names, or use .mp3). Keep them short (<1 s). If a file is
missing the app falls back to a plain system tone.
