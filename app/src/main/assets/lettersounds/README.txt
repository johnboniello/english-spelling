Drop English letter recordings here to replace the spoken letter NAMES with
real sounds in the games.

File format: .mp3 (keep them short — 0.3 to 1 second)

Expected filenames (only add the ones you have; missing ones fall back to the
text-to-speech letter name):

  a.mp3 b.mp3 c.mp3 d.mp3 e.mp3 f.mp3 g.mp3 h.mp3 i.mp3 j.mp3 k.mp3 l.mp3 m.mp3
  n.mp3 o.mp3 p.mp3 q.mp3 r.mp3 s.mp3 t.mp3 u.mp3 v.mp3 w.mp3 x.mp3 y.mp3 z.mp3

  hyphen.mp3  apostrophe.mp3  space.mp3

Where to find openly-licensed recordings:
  - Wikimedia Commons, "Category:English pronunciation"
      https://commons.wikimedia.org/wiki/Category:English_pronunciation
  - Lingua Libre (CC0 / CC-BY-SA 4.0)
      https://lingualibre.org/

Check each clip's licence and keep attribution where required.
After adding files, rebuild with ./build-apk.sh
